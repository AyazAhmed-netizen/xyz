Suno Recorder v2

1. Click any song on Suno to start playing.

2. Click the orange "🎙️ Record" button that appears next to the Play/Pause button.

3. When the song ends (or you stop sharing), the file will download automatically.

Format: WebM (High Quality). Convert to MP3 via any free tool if needed.
